# WearWise

**Dress smarter. Buy once. Wear forever.**

An interactive educational microsite teaching the "investment wardrobe" philosophy — cost-per-wear, quality recognition, and timeless style.

Built from the concepts in *"Style That Lasts: The Forever Wardrobe"* (MOSSO), rewritten as original copy and upgraded into three interactive tools.

## Stack
- Vite 8 · React 19 · TypeScript
- Tailwind CSS 4 · framer-motion 12
- Unsplash photography · Vercel deploy

## Getting started
```bash
npm install
npm run dev     # local dev
npm run build   # production build
```

## Structure
- `PRD.md` — product requirements + 10-phase plan
- `DESIGN.md` — design tokens & direction
- `src/` — components, sections, data, hooks
